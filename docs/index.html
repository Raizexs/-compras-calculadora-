✨ Características Principales

💱

Multi-Moneda

Soporte para CLP (Peso Chileno), USD (Dólar) y EUR (Euro) con conversión automática en tiempo real.

💾

Persistencia Local

Tus datos se guardan automáticamente usando AsyncStorage. Nunca pierdas tu lista de compras.

🎨

UI Moderna

Interfaz elegante con diseño Material, animaciones suaves y experiencia de usuario optimizada.

📊

Cálculo Automático

Total calculado en tiempo real con formato de números según la moneda seleccionada.

🗑️

Gestión Fácil

Agrega, elimina (mantén presionado) o limpia toda la lista con un solo toque.

📱

Cross-Platform

Funciona perfectamente en Android y iOS con el mismo código base.

🚀 Instalación Rápida

# 1. Clonar el repositorio
git clone https://github.com/Raizexs/-compras-calculadora-.git
cd compras-calculadora

# 2. Instalar dependencias
npm install

# 3. Iniciar el proyecto
npx expo start

# 4. Escanear QR con Expo Go
📱 Descarga Expo Go desde tu tienda de apps
